# TraxShop Complete V1

1. Extract ZIP.
2. Upload semua isi folder ke repository GitHub.
3. Pastikan `index.html` langsung di root repository.
4. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.

Fitur demo: produk, pencarian, kategori, sorting, keranjang, login nomor HP/ID, profil, saldo TraxPay demo, checkout, alamat, pembayaran demo, dan riwayat pesanan.

Catatan: ini frontend demo. Untuk produksi perlu backend/database, autentikasi aman, admin, stok, payment gateway, ongkir, notifikasi, dan keamanan server.
